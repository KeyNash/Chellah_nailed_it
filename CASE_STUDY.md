# Chellah Nailed It — Portfolio Case Study Draft

## Classification

Pending Nash’s confirmation: client work, personal work or concept work.

## Challenge

The original single-page site mixed genuine Chellah service details and imagery with stock imagery, unsupported performance claims, fabricated-looking testimonials and a booking form that displayed success without sending a real request.

## Nash’s role

To be confirmed before portfolio publication.

## Solution

A focused editorial beauty experience rebuilt on React, TypeScript, Vite and Tailwind CSS. The interface prioritises Chellah’s existing work, transparent pricing and a direct Instagram booking route. Unsupported claims were removed rather than presented as facts.

## Verified features

- Responsive single-page experience at 320, 375, 768, 1024 and 1440 pixels.
- Accessible navigation, visible focus, semantic headings and reduced-motion handling.
- Filterable nails, braids and locs gallery with keyboard-dismissable image preview.
- Existing services, prices, location wording, Instagram and TikTok details.
- Page metadata, social preview asset, favicon, structured business data and robots handling.
- Clean lint, production build and zero production dependency vulnerabilities as of 2026-09-06.

## Technology

React 19, TypeScript, Vite 7, Tailwind CSS 3 and Lucide React.
