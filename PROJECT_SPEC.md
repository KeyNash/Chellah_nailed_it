# Chellah Nailed It Rebuild Specification

## Goal

Rebuild the existing Chellah Nailed It site as a polished, responsive portfolio piece using the React, TypeScript, Vite and Tailwind stack from `Salon_project_1`.

## Allowed source material

- Business copy, services, price menu, location wording and social handles from the existing Chellah Nailed It site.
- Image files already stored in the Chellah Nailed It `Assets` directory.
- Technical patterns and dependencies from `Salon_project_1`.

## Exclusions

- No external or stock images.
- No invented testimonials, metrics, ratings, years in business, phone numbers, email addresses or outcomes.
- No fake form submission. Booking uses the existing Instagram profile until a verified direct channel is provided.

## Acceptance criteria

- One accessible page with navigation, services, filtered gallery, prices and visit/booking information.
- Responsive from 320px through desktop with no horizontal overflow.
- Keyboard-operable navigation, gallery controls and modal; visible focus and reduced-motion support.
- Valid metadata, social preview image and favicon using existing assets.
- Clean lint and production build.
