# Chellah Nailed It

Portfolio-ready single-page website for Chellah Nailed It, built with the React, TypeScript, Vite and Tailwind stack inherited from `Salon_project_1`.

## Content boundaries

- Uses only imagery and business details already present in the original Chellah Nailed It project.
- Omits unverified testimonials, review totals, years-in-business claims and contact details.
- Instagram is the primary booking route until a verified phone number or booking service is supplied.

## Local development

```powershell
npm.cmd install
npm.cmd run dev
```

## Verification

```powershell
npm.cmd run lint
npm.cmd run build
```

Before production, confirm the location wording, prices, social handles and preferred booking channel with the business owner.
